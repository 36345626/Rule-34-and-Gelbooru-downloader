Gelbooru Downloader by AMAYORI v1.0
===================================

Качалка картинок и видео с Gelbooru по тегам. Windows 10/11.
Программа — один файл GelbooruDownloader.exe. При запуске сразу появляется заставка
«Загрузка…»: пара секунд, пока программа распаковывается.

Что нового по сравнению с прошлой версией
-----------------------------------------
Исправлено:
- Любой сбой сети или сайта раньше считался «неверным API-ключом»: программа
  открывала настройки и не делала обещанных повторов. Теперь тип ошибки
  определяется правильно, повторы и «Продолжить» работают.
- Ключ API раньше попадал в журнал открытым текстом и хранился в config.json
  как есть. Теперь он вырезается из всех сообщений и хранится зашифрованным
  средствами Windows (DPAPI).
- Кнопка «Стоп» больше не зависает на десятки секунд.
- Большие картинки больше не подвешивают окно (превью готовится в фоне).
- Слишком длинные теги больше не ломают сохранение (лимит путей Windows).

Новое:
- Обход блокировки. В режиме «Авто» (по умолчанию) программа сама замечает,
  что сервер сайта не открывается, находит рабочий прокси из встроенного
  списка и ходит через него только к заблокированным серверам; остальное —
  напрямую. Можно указать и свой прокси / прокси VPN-клиента.
- Если связь пропала, программа сама ждёт и продолжает, когда сеть вернётся;
  при долгих сбоях сайта — пауза с сохранением и кнопка «Продолжить».
- Ход загрузки: полоса, «скачано / пропущено / ошибок», скорость, сколько
  осталось. Кнопка «Найти» показывает, сколько постов найдено.
- Подсказки тегов при вводе. Можно вводить теги, а не только ссылку.
- Предпросмотр, как на сайте: пока вводите теги, справа появляются картинки
  первой страницы поиска (двойной щелчок — открыть пост). Под ними — автор,
  персонажи и откуда они (как в колонках тегов на сайте); щелчок по имени —
  поиск по этому тегу, «все теги» раскрывает остальные.
- В предпросмотре: листание страниц (◀ ▶ под сеткой); двойной щелчок — арт
  в полный размер (← → — соседние, S — скачать); правая кнопка — скачать один
  или несколько выделенных артов в выбранную папку. Скачанные помечены ✓, и
  обычная загрузка их не повторяет.
- Вход на сайт прямо в программе (встроенный браузер): войдите или
  зарегистрируйтесь — программа сама заберёт ключ, а на Gelbooru ещё и включит
  «Display all site content» и «Always show original». Пароль программа не
  сохраняет; вход запоминается, как в обычном браузере.
- Фильтр «Без ИИ-артов», как на сайте: исключает посты с тегами ИИ.
- В углу окна — ник аккаунта, чей ключ используется, и подпись by AMAYORI.
- Ключ API — как раньше, одной строкой &api_key=…&user_id=…: программа сама
  её разбирает и сразу проверяет. Кнопки «Открыть страницу ключа» и
  «Регистрация», пошаговая подсказка; скопированную на сайте строку программа
  сама берёт из буфера обмена. Если сайт отдаёт посты без ссылок на файлы
  (выключены настройки аккаунта), программа скажет, что включить.
- Фильтр по рейтингу, тип файлов, лимит (0 — все).
- Не качает повторно уже скачанное. «Только новые» — докачать то, что
  появилось на сайте после прошлого раза (и из истории тоже).
- Несколько файлов одновременно (по умолчанию 3) — заметно быстрее.
- «Скачать всё» больше не упирается в предел глубины страниц API: листание
  идёт по номеру поста.
- Файлы называются номером поста (1234567.jpg) — по нему легко найти пост
  на сайте; теги видны в названии папки.
- Превью последних файлов лентой, «Открыть», «Показать в папке», «Пост на сайте».
- История: одна строка на запрос, кнопки «Подставить», «Докачать новые».
- Языки: русский, English, 中文, 日本語.

Старые настройки, ключ и история подхватываются автоматически.

Файлы
-----
GelbooruDownloader.py   — вся программа одним файлом (иконка, заставка и список
             прокси встроены). Название, цвета, адреса сайта — в разделе
             «sites» в начале файла.
build_exe.bat  — собрать exe
README_Gelbooru.txt — этот файл

Сборка exe
----------
1. Установите Python 3.10 или новее с python.org (галочка «Add Python to PATH»).
2. Запустите build_exe.bat — рядом появится GelbooruDownloader.exe. В первый раз он скачает
   около 250 МБ библиотек (из них встроенный браузер — около 170 МБ).
   Вариант папкой (запускается быстрее, без распаковки): build_exe.bat --folder

Где что лежит
-------------
- Настройки и история: %APPDATA%\GelbooruDownloader\
- В папке каждого запроса: .booru_ids.txt (номера скачанных постов),
  .booru_task.json (для «Продолжить»), failed_links.txt (что не скачалось).

Прокси
------
Бесплатные прокси живут недолго. Если «Авто» перестал находить рабочий,
в «Настройки → Подключение» вставьте свежий список (по одному в строке,
форматы ip:порт, http://…, socks5h://…) и нажмите «Проверить список».
Ключ API через прокси не утекает: соединение с сайтом идёт по HTTPS, прокси
видит только имя сервера.

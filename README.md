# Rule-34-and-Gelbooru-downliader
These are two small programs for viewing and downloading posts from the Rule 34 and Gelbooru websites. The idea is to download a batch or the entire collection of artwork and/or videos based on tags.

This isn't the first version, but it is the most complete one so far. It includes full functionality for searching and downloading posts from Rule34 and Gelbooru. The program features a built-in proxy for use if standard access is restricted. It was created using "vibecoding" with the help of ChatGPT and Claude Code.

Two versions of the software are provided: Lite and Full. The difference is that the Full version allows you to register or log in to the site via the built-in browser, whereas this feature has been removed from the Lite version.

To use the programs, you need an account, as the software utilizes your account's API to interact with the site on your behalf. PLEASE NOTE: YOU ARE SOLELY RESPONSIBLE FOR ANY ACTIONS TAKEN ON THE SITE; THIS PROGRAM IS MERELY A CONVENIENT TOOL.
